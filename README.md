# Message Service

Backend-сервис на Go для обмена сообщениями между пользователями в реальном времени с использованием WebSocket.

## Возможности

- Обмен сообщениями между пользователями в реальном времени через WebSocket.
- Создание и управление чатами.
- Сохранение сообщений в PostgreSQL.
- Асинхронная обработка событий с использованием Apache Kafka.
- Взаимодействие с внешними сервисами через gRPC.
- REST API для работы с чатами и сообщениями.

## Технологический стек

- **Язык программирования:** Go 1.25
- **HTTP-фреймворк:** Gin
- **Обмен сообщениями в реальном времени:** WebSocket (Gorilla WebSocket)
- **Брокер сообщений:** Apache Kafka
- **База данных:** PostgreSQL
- **ORM:** GORM
- **Межсервисное взаимодействие:** gRPC, Protocol Buffers
- **Документация API:** Swagger
- **Контейнеризация:** Docker

## Архитектура

Message Service отвечает за управление чатами и сообщениями, обеспечивает обмен сообщениями между подключёнными пользователями в реальном времени через WebSocket и обрабатывает события, получаемые от других сервисов через Kafka. Для постоянного хранения данных используется PostgreSQL. Для взаимодействия с другими backend-сервисами применяются Kafka и gRPC.
